SWF 로컬 뷰어 파일 배치

Chromium 53.0.2785.0 x86은 프로그램의 "Chromium 다운로드" 버튼으로 설치할 수 있습니다.
프로그램은 GitHub Release에서 Chromium ZIP을 내려받고 SHA-256을 검증한 뒤 아래 위치에 설치합니다.

Tools\FlashViewer\
  Chromium\
    chrome.exe
    (Chromium 53.0.2785.0 x86 런타임 파일)
  PepperFlash\
    pepflashplayer.dll
    manifest.json   (있으면 권장, 없으면 버전 99.99.99.99로 시도)

Pepper Flash는 다운로드 패키지에 포함되지 않습니다.
사용자가 x86 pepflashplayer.dll을 직접 준비해 Tools\FlashViewer\PepperFlash 폴더에 넣어야 합니다.

조건
- Chromium은 53.0.2785.0 x86을 기준으로 사용합니다.
- pepflashplayer.dll도 반드시 x86이어야 합니다.
- 이 뷰어는 로컬 SWF 확인 전용으로 사용하고 일반 웹 브라우징에는 사용하지 마세요.
